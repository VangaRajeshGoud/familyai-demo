# FamilyAI — GitHub Static Demo

A responsive, GitHub Pages-ready product prototype for **FamilyAI — AI-Powered Family Grocery & Lifestyle Platform**.

## Demo pages
- `index.html` — product vision
- `dashboard.html` — family home / daily intelligence
- `family.html` — family profile and remembered routines
- `grocery.html` — grocery catalogue, organic/fresh categories and sugar warning demo
- `ai.html` — AI companion + voice demo
- `meals.html` — weekly meal planner and Sunday chicken basket
- `health.html` — health preference and ingredient-warning experience
- `offers.html` — restaurant offer experience
- `cart.html` — editable family basket and approval flow
- `admin.html` — owner/admin and business intelligence demo

## Included concepts
- Voice-first natural-language shopping
- Family memory and recurring monthly basket
- Vegetarian / non-vegetarian preferences
- Sunday chicken/mutton tradition concept
- Organic vegetables and fruits
- Daily/recurring water essentials
- Ingredient-level meal planning
- Health-aware warnings for configured dietary preferences
- AI roles: Health Friend, Teacher, Family Friend, Gym Friend, Shopping Assistant
- Restaurant offers and partnership concept
- Budget and savings experience
- Explicit approval before purchase
- Responsive desktop, tablet and mobile layouts
- LocalStorage demo basket

## Important
This is a **static UI/UX prototype**, not a production medical, commerce or payment system. Product prices, restaurant offers and admin metrics are illustrative demo values. Health guidance should not be presented as diagnosis or a substitute for professional medical advice. Production restaurant offers must come from active registered partners.

## GitHub Pages
Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the repository settings. Open `index.html` as the landing page.

## Production path
React + TypeScript + Tailwind → Java 17 / Spring Boot REST API → H2 local / PostgreSQL production → JWT/OTP → catalogue/inventory → AI provider → voice pipeline → secure payment → notifications → production Android/iOS.
